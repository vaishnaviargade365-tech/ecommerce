# UI/UX Requirements

## Design Goal

Create a simple, clean, modern and professional e-commerce interface.

Do not over-design the application.

## Customer Website

Pages:

```text
Home
Products
Product Details
Cart
Checkout
Login
Register
My Orders
```

## Navigation

The navbar should provide easy access to:
- Home
- Products
- Cart
- Login/Register or customer account
- My Orders when authenticated

## Product Layout

Use responsive product cards containing:
- Image
- Name
- Price
- Category
- Add to Cart button

## Product Search and Filter

Provide:
- Search
- Category filter

Example:

```text
All | Electronics | Fashion | Shoes
```

## Cart UI

Display:
- Product
- Quantity
- Quantity controls
- Price
- Remove action
- Total price

Prevent quantity from exceeding stock.

## Admin Dashboard

Use:
- Responsive sidebar
- Tables
- Forms
- Cards where appropriate

Admin sections:
- Categories
- Products
- Orders

## Feedback States

The UI should include:
- Loading states
- Empty states
- Toast messages
- Delete confirmation dialog
- Basic validation messages

## Responsive Design

The application must work on:
- Mobile
- Tablet
- Desktop

Tailwind CSS should be used for styling.
